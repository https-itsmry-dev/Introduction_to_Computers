## Introduction To Computers

**Computer** is an <ins>electronic device</ins> that processes data according to the given instructions given by the end-user. It takes input (data), processes it using a central processing unit (CPU), stores information, and produces output (results) to perform various tasks which is then, referred to as information or **processed data**. In modern day and age, computers are used in almost every industry.

## Types of Computers

The categories in which **Computers** can be classified are mentioned below:
* Based on Their **Size**
* Based on Their **Purpose**
* Based on Their **Data Handling**

### <ins>Based on Their **Size** </ins>

Based on size, we have the following type of computers 
* Supercomputer
* Mainframe
* Minicomputer
* Microcomputer (Personal Computer)

### <ins>Based on Their **Purpose** </ins>

Based on Purpose, we have the following type of computers 
* General-Purpose Computer
* Special-Purpose Computer

### <ins>Based on Their **Data Handling** </ins>

Based on Data Handling, we have the following type of computers 
* Analog Computer
* Digital Computer
* Hybrid Computer

### Primary Use Case of Computers Which Are Categorized On The Basis of Size using a **Table**
